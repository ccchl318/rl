# 同轨迹验证选模规则对照

开始：2026-11-16T09:57:21+08:00；完成：2026-11-16T11:02:57+08:00。

种子 2/3/4 各从头训练一次；每次 6000 次退火 + 6000@6e-5 + 6000@2e-5，共 147,456,000 环境步，epochs=10，初始 lr=6.25e-4，EMA=0.999，保留 value clipping。

每个种子的两套规则使用完全相同的原始/EMA 训练轨迹。新规则每 250 次迭代评估 500 局；旧规则每 25 次评估 50 局；验证种子均从 12345 开始。选模目标均为棋盘和 + 250×P256。验证预算按单套规则计算相同，实验旁路同时运行两套。

每模型独立贪心终测 10,000 局，种子 2000000–2009999；终测不用于重新选 checkpoint。末尾 EMA 为预先指定的固定对照。
